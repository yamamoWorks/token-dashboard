# 3.5インチ Rev.A に表示する

- 種別: 拡張
- UI確認: 不要

## 分岐条件
主成功系列の表示画像を TURZX に送る処理で、選択された表示先が3.5インチ Rev.A、表示プロファイルが `compact-gauge-480x320` である。メーカーのソフトなど、対象COMポートを使用する他のアプリは終了している。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が3.5インチ Rev.A を接続する | VID/PID `1A86:5722` とシリアル番号／PNP Device ID の `USB35INCHIPSV2` から対象機を検出し、既存の表示先一覧に表示する |
| 2 | 利用者が表示先と3.5インチの表示プロファイルを選ぶ | 既存の設定操作で保存し、対象機の現在のCOMポートを特定する |
| 3 | アプリの起動または表示更新が発生する | 対象COMポートを115200 baud、RTS/CTS有効で開き、Landscapeを設定する |
| 4 | 選択した取得元から利用状況が届く | 既存のCompact Gaugeで480×320画像を生成し、RGB565 Little Endianに変換して、幅8pxの縦帯ごとに左から右へ送信する |
| 5 | 利用状況の更新または自動ページ送りの時刻が到来する | 既存の設定に従った最新画像を送る。プレビューは利用者が選択したページを維持する |
| 6 | 利用者が対象機を抜き差しする | 切断した接続を閉じ、再検出した現在のCOMポートで接続し直して最新画像を送る |
| 7 | 利用者が `Exit` を押す | 接続中の3.5インチ Rev.A に `RESET`（101）を送信し、その後Serial接続を閉じてアプリを終了する。送信に失敗しても接続を閉じ、終了する |

## 受け入れ条件
- COM番号を固定せず、COM番号が変わった場合も同じ対象機を検出・選択できる。
- VID/PIDだけでRev.Aと判定せず、Rev.Bは対象に含めない。
- `Automatic` は既存どおり識別子順の先頭を選ぶ。特定機器の選択中は、切断しても別の機器へ切り替えない。
- Serial接続は115200 baud、RTS/CTS有効とする。
- 接続時に `SET_ORIENTATION`（121）でLandscapeを設定する。
- 画面を幅8pxの縦帯60本に分け、左端の縦帯から順に送る。各縦帯では `DISPLAY_BITMAP`（197）の6バイトコマンドで領域 `(x,0)–(x+7,319)` を指定し、続けてその縦帯のRGB565LEデータ5,120バイト（縦帯内は左→右、上→下）を送る。1本を送り終えてから次の縦帯へ進み、1フレームで合計307,200バイトの画像データを送る。他のフレームや縦帯とデータを混在させない。
- 実機で画像の向き・色・表示内容が正しいことを確認する。
- 実機で、縦帯送信による表示内容・色・向きが正しく、描画欠けや破損がないことを確認する。
- 送信は逐次実行し、送信待ちは最新の1枚だけ保持する。通信失敗で取得処理・プレビュー・アプリを停止しない。
- 表示プロファイルと物理デバイスの種類を別に扱い、機器選択でプロファイルを自動変更しない。画像サイズが機器に合わない場合は送信せず、原因をログに記録する。
- 終了時は、接続中の3.5インチ Rev.A に6バイトの `RESET` コマンド `00 00 00 00 00 65` を送信してからSerial接続を閉じる。未接続の場合はリセットのために接続し直さない。
- `RESET` の送信に失敗しても、Serial接続のクローズとアプリの終了を行う。
- 実機で終了時のリセットが動作することを確認する。リセット後の画面内容は実機確認で確かめ、未検証の表示状態を保証しない。
- 9.2インチは既存の90度回転・JPEG品質85・WinUSB送信と、終了時の再起動を維持する。
- 今回追加するRESETコマンドの単体テスト、終了処理の検証、任意矩形の `DISPLAY_BITMAP` 生成と縦帯のRGB565LE抽出の単体テストは、段階5の承認後、段階6で追加する。必要な既存テスト、lint、build、文書検査も通す。
- 最終確認は実Hubに接続したデスクトップアプリと3.5インチ実機で行う。
- GPL-3.0の参照コードはコピー・逐語移植せず、プロトコル情報を基に独自実装する。
- Brightness、Screen On/Off、終了時以外のReset操作、Clear、LED制御、差分更新、通信速度最適化は対象外とする。

## 補足
既存の画面・描画を利用するため段階2・3は省略し、実機表示と終了時のリセットは段階5で確認する。既存の設定項目を使い、新しい保存項目やDBは追加しない。
