# Windows ディスプレイ消灯に連動して転送を停止・再開する

- 種別: 拡張
- UI確認: 不要
- 関連: Issue #21

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | Windows にサインインしてアプリを起動する | Windows セッションのディスプレイ電源通知を登録し、従来どおり TURZX に最新画像を送る。起動時に状態が不明な場合は既存の転送動作を保つ |
| 2 | Windows がディスプレイを消灯する | TURZX の送信ループで進行中の送信完了後に、選択中デバイスの Exit（リセット／再起動）を一度送って Close し、画像転送を停止する |
| 3 | ディスプレイが OFF のままデータが更新される | 利用状況取得とプレビュー描画は続ける。TURZX に画像を送らず、最新フレームのみ保持する |
| 4 | Windows がディスプレイを点灯する | 再接続してその時点の最新フレームを送る。切断中なら既存の再試行処理で復旧する |
| 5 | PC がスリープする | 可能なら同様に転送を停止する。スリープ直前の USB 送信成功は保証しない。復帰後は Windows の ON 通知を待つ |

## 受け入れ条件

- 同じ OFF／ON 通知が連続しても重複処理しない。短時間で切り替わっても OFF→ON の順序を保つ。
- Windows の DIMMED（減光）は OFF と扱わない。
- 9.2 インチと 3.5 インチ Rev.A はそれぞれ既存の Exit を利用する。リセットによりバックライトまで物理消灯するかどうかは実機で個別に確認する。
- TURZX 自体の物理電源ボタン、Windows に通知されない外部モニターの電源操作は対象外。
- サーバーモードおよび非 Windows のビルドは電源通知機能なしで動作する。
