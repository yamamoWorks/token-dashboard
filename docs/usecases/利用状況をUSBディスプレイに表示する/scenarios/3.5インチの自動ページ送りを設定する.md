# 3.5インチの自動ページ送りを設定する

- 種別: 拡張
- UI確認: 要

## 分岐条件
Display 画面で `compact-gauge-480x320`（TURZX 3.5 Inch）が選択され、利用者が実機の自動ページ送り設定を変更する。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が Display 画面を開く | Style カード内のプレビュー右側に `Auto page` と `Interval` を表示する |
| 2 | 利用者が `Auto page` を ON または OFF に切り替える | 設定を即時保存して実機表示へ反映する。OFF の場合は実機を第1ページへ戻し、自動ページ送り用の高速再描画を停止する |
| 3 | 利用者が `Auto page` を ON にする | `Interval` を操作可能にする |
| 4 | 利用者が `Interval` で `5 sec`、`10 sec`、`15 sec`、`30 sec`、`60 sec` のいずれかを選ぶ | 設定を即時保存し、既存の描画タイマーを選択した間隔へ切り替える |
| 5 | 利用者がプレビュー下部のページインジケーターをクリックする | プレビューだけを選択したページへ切り替え、実機の現在ページや自動ページ送り状態は変更しない |

## 受け入れ条件
- 3.5インチ選択時は、Style カード内のプレビュー右側の空き領域に `Auto page` と `Interval` を表示する。
- 9.2インチ（`ultra-wide-1920x462`）選択時は、自動ページ送り設定を表示しない。
- 3.5インチ選択時は、現在1ページしかなくても自動ページ送り設定を表示する。
- `Auto page` の変更は即時保存・即時反映する。
- `Auto page` が ON の場合は、保存済みの間隔で全ページを順番に巡回する。
- `Auto page` が OFF の場合は、実機を第1ページに固定し、利用状況更新や残り時間更新による再描画でも第1ページを維持する。
- `Auto page` が OFF の場合は、自動ページ送りのためだけの高速再描画を行わない。
- `Auto page` が OFF の場合は `Interval` を操作不可にする。
- `Interval` は `5 sec`、`10 sec`、`15 sec`、`30 sec`、`60 sec` から選択する。
- `Interval` の変更は即時保存・即時反映し、次回起動後も保持する。
- 既存設定ファイルに自動ページ送り設定がない場合は、`Auto page = ON`、`Interval = 10 sec` として扱う。
- 設定変更時は既存の描画ループを起こして周期を更新し、ページ送り専用の追加 goroutine / ticker は作らない。
- プレビューは `Auto page` が ON でも時間経過では切り替わらず、下部のページインジケーターをクリックしたときだけ切り替わる。
- プレビューで選択したページは実機の現在ページに影響しない。
