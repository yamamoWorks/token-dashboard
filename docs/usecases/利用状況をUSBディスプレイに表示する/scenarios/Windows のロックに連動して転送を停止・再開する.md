# Windows のロックに連動して転送を停止・再開する

- 種別: 拡張
- UI確認: 不要
- 実現パターン: UCP-1

## 分岐条件

「利用状況をUSBディスプレイに表示する」の実行中に、利用者の Windows セッションがロックされる。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 利用者が Windows をロックする | 新しい画像転送と再接続を停止する。進行中の送信完了後に、接続中の選択デバイスへ既存の `Exit()`（Reset）を一度実行し、`Close()` する |
| 2 | ロック中に利用状況が更新される | 利用状況の取得とプレビュー描画を続け、最新フレームだけを保持する。USB への画像転送と再接続は行わない |
| 3 | 利用者が Windows のロックを解除する | ディスプレイが OFF でなければ再接続し、最新フレームの転送を再開する。OFF の場合は ON 通知を待って再開する |

## 受け入れ条件

- 9.2インチと3.5インチ Rev.A の双方で既存のデバイス別 `Exit()` を利用する。
- 消灯処理ですでに接続を閉じている場合、Reset のために再接続しない。
- ロック中は、ディスプレイの ON 通知が届いても転送を再開しない。
- ロック・解除の重複通知で Reset・再接続・再送信を繰り返さない。
- 短時間のロック・解除や転送中のロックでも、送信・Reset・Close が競合しない。
- 解除後は古いフレームを順次送らず、最新フレームを表示する。USB が未接続なら既存の再試行処理で復旧する。
- Reset が失敗しても接続の解放を試み、失敗をログに記録する。
- Reset 後の液晶・バックライトの物理消灯は保証しない。
- サーバーモードと非 Windows ビルドの既存動作を維持する。
